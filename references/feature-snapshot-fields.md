# 特征快照字段字典

本文件维护四个受控特征包共用的 JSON 特征字段口径。内容由项目维护者确认，可用于解释元数据字段；具体特征的名称、取值、加工公式和血缘仍以本地查询命令返回的证据为准。

| JSON 字段 | 中文含义 | 取值或说明 |
|---|---|---|
| `featureCode` | 特征 Code | 特征的唯一编码。 |
| `featureColumnName` | 特征字段名 | 一般指特征在数据表中的字段名。 |
| `featureName` | 特征名称 | 一般指特征的中文名称。 |
| `groupCode` | 特征组 Code | 特征所属加工特征组的编码。 |
| `groupName` | 特征组名称 | 特征所属加工特征组的名称。 |
| `domainCode` | 特征主题域 | `UID` 表示用户主题域。其他取值未维护时不得自行解释。 |
| `includeTodayFlag` | 回溯是否包含当天 | `0` 表示不回溯当天，`1` 表示回溯当天。 |
| `timeRange` | 特征缓存天数 | 单位为天。该字段不是特征统计或计算的回溯窗口。 |

回答字段含义时，区分“缓存天数”和特征名称、SQL 中表达的统计窗口。例如 `timeRange=30` 只能解释为特征缓存 30 天，不能据此断言特征计算最近 30 天的数据。

无法确认的字段取值明确说明尚未维护，不要按字段名或行业常识补全。
